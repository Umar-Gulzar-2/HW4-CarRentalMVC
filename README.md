# Car Rental MVC - HW 4

A small ASP.NET Core MVC application for the Web Technologies HW 4.

## Requirements
- .NET 10 SDK (latest stable LTS)
- A Visual Studio version that supports .NET 10, with the ASP.NET and web development workload
- Internet connection for Bootstrap 5.3 CDN styling

Install the .NET 10 SDK from https://dotnet.microsoft.com/en-us/download/dotnet/10.0 if it is not already installed.

## Run in Visual Studio
1. Extract the ZIP file.
2. Open `CarRentalMVC.csproj` in Visual Studio 2022.
3. Allow NuGet restore if prompted.
4. Press **F5** (or **Ctrl+F5**) to run.
5. The application opens on the Available Cars page.

The application uses in-memory lists. Bookings reset when the application restarts, as required by the assignment.
